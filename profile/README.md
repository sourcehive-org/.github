## 🐝 Build in the open with developers across borders

**SourceHive** is a not-for-profit, developer-led community. We believe open-source innovation thrives when talent comes together across boundaries: geographic, professional and technical.

We run **hackathons**, **contributor sprints** and **maintainer office hours** for open-source projects. Pick an issue, find a team, ship a pull request.

**Tracks this season:** Web & APIs · AI / ML · Developer tools · Cloud & infra · Open data

## 🚀 Your first contribution

No gatekeeping. There's a clear path from clone to merged pull request.

| Step | What happens |
|---|---|
| 1️⃣ **Pick an issue** | Filter labelled issues by language, difficulty and time needed. Each one has a scoped task and a test to pass. |
| 2️⃣ **Pair with a maintainer** | Book a 20-minute slot in weekly office hours, or ask in the project channel. Reviews within 72 hours. |
| 3️⃣ **Open your pull request** | Merged contributions show on your community profile and count toward event rankings. |

## 🤝 Code of conduct

Be respectful, assume good faith, and keep the work in the open. Harassment, hate and leaking private data are out. Mentors and organisers can remove someone from an event. [Read more](https://sourcehive.buzz/#conduct).
