# Getting help 🐝

- **Questions and ideas:** start a thread in [GitHub Discussions](https://github.com/orgs/sourcehive-org/discussions).
- **Bugs and feature requests:** open an issue in the relevant repository using the templates.
- **Security issues:** see [SECURITY.md](SECURITY.md). Please don't post them publicly.
- **Partnerships, events and everything else:** reach us through [sourcehive.org](https://www.sourcehive.org), on [LinkedIn](https://www.linkedin.com/company/sourcehivecommunity/) or on [Instagram](https://www.instagram.com/sourcehive.uae/).
